# Studybooks

Фото й файли лекцій → дві PDF-книги на кожен предмет. Сайт (FastAPI) приймає матеріали, а фоновий воркер читає їх моделлю (Claude Code або OpenRouter), складає розділи й збирає книги через pandoc і Typst.

## Що вміє

- **Дві книги на предмет.** `clean.pdf`: англійською, виправлена й доповнена за підручниками, з вижимкою розділу й словником термінів. `original.pdf`: дослівна транскрипція мовою оригіналу плюс оригінальні фото.
- **Розділ книги = день заняття.** Доповнення до минулої лекції лягає в той самий розділ.
- **Файли:** фото, PDF (також «без редагування»), Office, HTML.
- **Інтерактивні сторінки** (симуляції, калькулятори) на запит. Перед збереженням сторінка **запускається в ізольованому контейнері**, її елементи керування перебираються, а помилки йдуть моделі на виправлення.
- **Edit:** зміна інтерактивної сторінки, розділу книги чи всієї книги текстовим запитом, зі скріншотами (вставка Ctrl+V), з відкатом на крок.
- **Екзаменаційні білети** з відповідями (PDF), жеребкування білета.
- **Спільна книга** для всіх учасників, пропозиції доповнень зі злиттям в основну книгу через адміна.
- **Двигуни:** Claude Code (власний вхід кожної людини) або OpenRouter, зокрема безкоштовні моделі з автоперемиканням. Турбо-режим, ліміти, зупинка, зупинки на 70/80/90 % ліміту.
- **Інтерфейс** українською й англійською, світла й темна тема; публічний доступ через Cloudflare tunnel (акаунти, ліміти).

## Як це працює

```
сайт ─upload─► inbox ─► воркер (sb.py) ─► library (git) ─► pandoc + Typst ─► books/<предмет>/{clean,original}.pdf
                          порція = 12 сторінок, 3 проходи:
                          1 транскрипція  2 звірка з підручниками  3 чистий англійський текст
```

Код перевіряє, а не довіряє моделі: вихід моделі проходить `check_md` (pandoc), `validate_change`, збірку Typst і запуск сторінки; текст від людей завжди вважається недовіреним.

## Склад

| Що | Файли |
|---|---|
| Бекенд (черга, двигуни, збірка книг) | `sb.py` |

## Запуск

Потрібні: Linux, Python 3.12, pandoc 3.7, Typst 0.15, LibreOffice (для Office-файлів), Node 22 і docker (перевірка сторінок), Claude Code CLI та/або ключ OpenRouter.

```bash
python -m venv .venv
.venv/bin/pip install fastapi uvicorn PyYAML pymupdf pillow pillow_heif python-multipart
(cd pagecheck && npm install --omit=dev) && docker pull node:22-alpine

export SB_DATA=./data SB_ADMIN=<uid-адміна> SB_BASE_URL=http://127.0.0.1:8810
.venv/bin/uvicorn web:app --host 127.0.0.1 --port 8810     # сайт
.venv/bin/python sb.py kick                                # воркер: обробити чергу (по таймеру або після кожного завантаження)
```

Основні змінні: `SB_DATA` (дані), `SB_ADMIN` (хто адмін основної книги), `SB_MODEL` (модель за замовчуванням), `SB_PUBLIC=1` (публічний екземпляр за тунелем), `SB_PAGECHECK=0` (вимкнути запуск сторінок). Решта описана в [docs/DETAILS.md](docs/DETAILS.md).

## Тести

Набори `tests/test_*.py` працюють офлайн, з фейковим двигуном і окремою `SB_DATA`. Вони розраховані на запуск із кореня **копії** проєкту: скопіюй у неї код, `tests/fake_*.py` лишається в `tests/`, а `test_*.py` кладуться в корінь.

```bash
cp tests/test_*.py .         # у копії проєкту, не в репозиторії
SB_DATA=/tmp/x SB_CLAUDE=$PWD/tests/fake_claude.py .venv/bin/python test_days.py
node tests/check_page_dict.js        # словник сторінки (uk/en)
```

Справжній Claude чи OpenRouter у тестах не викликаються. `test_pagecheck.py` додатково потребує docker і `SB_PAGECHECK_DIR=pagecheck`, інакше пропускається.
